# Synthetic validation results

These files were generated from fictional regions by the public `ci` profile.
They exercise data contracts, analysis summaries, claim rendering, and the five
main SVG figures. Static manuscript and submission artifacts are excluded from
the public release. These files are not perturbed, masked, or resampled Hunan
observations and do not support scientific or policy inference.

CSV, JSON, and SVG synthetic outputs are dedicated under CC0-1.0. The README is
provided under CC-BY-4.0. Every file is also registered and hashed in the root
`PUBLIC_EXPORT_MANIFEST.json`.
