# Hunan HFMD: reproducible data, scripts and results

This repository contains only the public materials needed to inspect and
reproduce the released outputs for the Hunan hand, foot and mouth disease
(HFMD) study.

```text
data/       Public aggregate Hunan tables and fully synthetic input data
scripts/    One dependency-free reproduction script
results/    Tables and SVG figures generated by that script
```

## Reproduce

Python 3.10 or newer is the only requirement.

```bash
python3 scripts/reproduce.py
python3 scripts/reproduce.py --check
```

The first command rebuilds `results/`. The second rebuilds everything in a
temporary directory and verifies that every committed result is identical.
Input and output SHA-256 digests are recorded in the data and result manifests.

## What the two data sets mean

- `data/hunan_aggregate/` contains disclosure-approved, province-level or
  model-summary tables from the study. The script verifies these tables and
  reproduces the public summary figures and key-finding table. These aggregates
  do **not** permit re-estimation of the restricted record-level analysis.
- `data/synthetic/` contains deterministic records for fictional regions. The
  script runs an end-to-end aggregation and rolling-validation example on these
  records. Synthetic outputs test the public computation and are not Hunan
  estimates.

Restricted surveillance records, exact dates, small-area identifiers,
vaccination records, fitted unit-level panels and bootstrap replicates are not
distributed.
